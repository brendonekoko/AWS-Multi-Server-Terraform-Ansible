Featured Work

AWS Multi-Server Infrastructure Automation

A hands-on cloud engineering project demonstrating automated infrastructure provisioning and server configuration.

Project Overview

I used Terraform to provision five Amazon Linux EC2 instances within a custom AWS Virtual Private Cloud. The environment includes a public subnet, internet gateway, route table, security group, and SSH key pair.

After provisioning the infrastructure, I used Ansible to connect to all five servers, install Apache HTTP Server, manage system services, and deploy a consistent website across the fleet.

01 — Provision: Created AWS infrastructure using Terraform.

02 — Connect: Configured SSH and Ansible inventory.

03 — Automate: Installed and enabled Apache on five servers.

04 — Deploy: Published a custom website using Ansible.
